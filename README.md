# Zomato Clone Backend 🍔

This project is a backend implementation of a food delivery application built using Node.js and Express.js.

## 🚀 Features

* User authentication (JWT-based)
* Food items API
* Like / Unlike functionality
* RESTful API structure
* MVC architecture

## 🛠 Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose

## 📁 Project Structure

* controllers/
* models/
* routes/
* middlewares/
* services/

## ⚙️ Setup Instructions

1. Clone the repo
2. Run `npm install`
3. Create `.env` file
4. Run `npm start`

## 📌 Note

This project was built for learning backend development and understanding API architecture.
